## ¿Qué significa el B2290? {#meaning}

El código **B2290** se define formalmente como **Error en el Sistema del Sensor de Clasificación de Ocupante** (*Occupant Classification System Sensor Fault*).

Este código pertenece a los sistemas de carrocería (Body) y gestiona la seguridad pasiva de las bolsas de aire (SRS). El código se genera cuando el módulo principal de control de restricciones (RCM) detecta una anomalía eléctrica, una interrupción de señal o una pérdida de calibración de datos proveniente del tapete sensor de peso colocado dentro del asiento del copiloto. Este sistema (OCS) se encarga de determinar si el pasajero delantero es un adulto, un niño o si el asiento va vacío, calculando así si es seguro o no desplegar la bolsa de aire frontal en un choque.

## ¿Qué tan grave es el B2290? {#serious}

La severidad de este código es **alta**. Aunque no afectará el encendido del motor ni los sistemas de tracción del vehículo, compromete directamente la vida del acompañante en caso de un siniestro vial.

```callout
¡Peligro!: Cuando el código B2290 está presente y el testigo de Airbag en el tablero está encendido, la computadora entra en una estrategia de falla segura (Failsafe). En la gran mayoría de fabricantes, esto significa que la bolsa de aire del pasajero delantero se desactivará por completo para evitar despliegues erróneos, dejando al copiloto sin protección frontal ante un impacto fuerte.
```

## ¿Puedes conducir con el B2290? {#drive}

**El automóvil es físicamente apto para conducir hacia el taller mecánico, pero no se recomienda transportar pasajeros en el asiento delantero.** > Se aconseja solucionar este problema técnico de manera inmediata. Si es indispensable utilizar el auto, el copiloto debería viajar en los asientos traseros, los cuales cuentan con sistemas de retención mecánicos independientes (cinturones de seguridad) que no se ven anulados por este código.

## Síntomas comunes del B2290 {#symptoms}

- Testigo de las Bolsas de Aire (SRS) encendido de forma fija en el tablero
- Indicador luminoso central "PASS AIRBAG OFF" encendido de forma permanente con un adulto sentado
- En vehículos Ford/Mazda, la luz de Airbag parpadea en secuencias específicas (Código de destello de lámpara - LFC) antes de quedarse fija
- El escáner de diagnóstico muestra códigos de error en el apartado de carrocería que no se pueden borrar

## ¿Qué causa el B2290? {#causes}

```cause
Arnés dañado o desconectado bajo el asiento | alta | El deslizamiento del asiento o guardar objetos debajo de este muerde, jala o desconecta el arnés amarillo del sensor de clasificación.
Pérdida de la calibración del punto cero | alta | Variaciones de tensión en la batería o desmontar el asiento descalibran los sensores de peso del riel, requiriendo un reajuste por software.
Humedad severa por lavado de tapicería | media | El agua o líquidos derramados en el cojín se filtran al tapete de gel interior, dañando las pistas eléctricas por cortocircuito.
Fractura interna del tapete sensor | media | Apoyar las rodillas con fuerza o colocar objetos punzantes sobre el asiento corta las celdas de presión internas del elemento sensor.
Falla de hardware en el módulo satélite OCS | baja | Daño de componentes internos en la pequeña microcomputadora atornillada bajo la estructura metálica del asiento del copiloto.
```

## Cómo diagnosticar el B2290 {#diagnosis}

```diagnosis
Conecte un escáner automotriz que tenga cobertura para sistemas SRS/Airbag. Acceda al módulo RCM o al módulo OCS (según la marca) y lea los sub-códigos de falla de 2 o 4 dígitos anexos al B2290 (por ejemplo, circuito abierto, cortocircuito a batería o falla de calibración). Esto le indicará si el problema es de cableado o de software.
```
```diagnosis
Gire el switch a OFF, retire la llave y desconecte el polo negativo de la batería. Espere de 5 a 10 minutos para que se descarguen por completo los capacitores del sistema SRS. Inspeccione visualmente los conectores debajo del asiento del pasajero. Desconecte el arnés amarillo grande, verifique que no tenga pines doblados, sulfatados ni sarro y asegúrese de que haga un clic firme al reensamblarlo.
```
```diagnosis
Vuelva a conectar la batería, encienda el switch en posición ON y acceda con el escáner a la línea de datos en tiempo real (Live Data) del módulo de clasificación de ocupante. Observe el parámetro de 'Peso Detectado' o 'Passenger Weight'. Con el asiento vacío debe marcar 0 kg o un valor muy cercano. Pídale a un adulto que se siente; el valor debe cambiar inmediatamente de acuerdo con el peso real de la persona. Si se queda estático en un valor errático o marca error, el sensor está dañado o descalibrado.
```
```diagnosis
Si los datos de peso están activos pero fuera de rango, intente realizar una calibración del punto cero utilizando el escáner (función 'OCS Zero Point Reset' o 'Occupant Classification Calibration'). Siga los pasos al pie de la letra: el coche debe estar en una superficie completamente nivelada, el asiento totalmente vacío, las ventanas cerradas y nadie debe tocar el coche durante el proceso. Si la calibración falla con código de error, el tapete sensor interno del cojín está dañado.
```
```diagnosis
Mida el voltaje de alimentación que llega al módulo del asiento desde el RCM con un multímetro digital en escala de Voltaje DC. Debe registrar 12V de alimentación de ignición y una tierra con resistencia menor a 0.5 Ohmios. Si el voltaje falta, revise el fusible del Airbag en la caja de fusibles del habitáculo.
```

## Cómo reparar el B2290 {#repairs}

```repair
Calibración y reajuste del punto cero del sensor OCS | 15–20 min | intermedio
Si el escáner indicó un error de calibración o se desmontó el asiento previamente, retire todos los objetos del asiento del copiloto. Conecte el escáner con el motor apagado y la ignición en ON, acceda al módulo de Clasificación de Ocupantes y ejecute la rutina de calibración. Borre los códigos de falla una vez que el software confirme que el reajuste fue exitoso.
```
```repair
Sustitución del tapete sensor de presión u ocupación | 60–90 min | avanzado
Si las pruebas confirmaron que el tapete de gel interno está cortado o quemado por humedad, desmonte los cuatro tornillos que sujetan el asiento al chasis del coche. Desconecte los arneses de seguridad y retire el asiento. Desmonte el guarnecido exterior de plástico y desprenda las grapas de la tapicería de tela o piel del cojín inferior. Retire el tapete dañado, coloque el nuevo sensor original alineándolo perfectamente, vuelva a tapizar y monte el asiento.
```
```repair
Reparación y encintado del cableado del arnés amarillo | 15–30 min | básico
Si se localizaron cables pelados o restregados contra los rieles mecánicos del asiento, corte la sección del cable dañado. Instale tubo termocontráctil, realice una unión por soldadura de estaño y aísle el cableado con cinta de tela automotriz de alta resistencia térmica para evitar fricciones futuras. Asegure el arnés con cinchos plásticos a la estructura del asiento para que no cuelgue.
```
```repair
Sustitución del módulo de control OCS satélite | 30–45 min | intermedio
Si el módulo electrónico atornillado debajo de la estructura del asiento sufrió un cortocircuito por líquidos, desmonte el conector, retire las tuercas de sujeción y cambie el módulo por una refacción nueva original con el mismo número de parte. Al cambiar el módulo electrónico, es estrictamente obligatorio realizar la recalibración de peso con el escáner.
```
